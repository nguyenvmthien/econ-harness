# Econ workspace rules
- Chat in Vietnamese; manuscript prose in English. Read the project's `PLAN.md` and `LOG.md` first except for standalone `/ae-phacking` and `/ae-exogenous`, where they are optional context if present.
- `data/raw` is read-only for agents: add sources via `R/00_download.R` (or the user drops files), then `ae_register_raw()`. Cleaning happens in code, never by editing raw files.
- Estimation code is free-form: any script, any order, exploratory work allowed; models can be run without a locked PLAN. Results produced before the PLAN §9 row that covers them was written are EXPLORATORY and cannot support a CAUSAL verdict (`ae-design`).
- Tables: build every results table in R from fitted model objects with standard packages (`modelsummary`, `datasummary`, `fixest::etable`) and export the finished table (`ae_export_table()`/`ae_export_df()` -> `output/tables/<name>.html` + `.md` + `.rds`). Do not write DOCX during estimation; DOCX only via `Rscript render.R docx` at the final step. Never write coefficients to CSV/text and rebuild a table by hand or at render time.
- **Viewer first**: every table and manuscript is checked in the RStudio Viewer (HTML) before any DOCX. After exporting tables or editing the manuscript, render HTML (`Rscript render.R`) and give the user the exact line to open it in the Viewer (`ae_view_table("<name>")` or `ae_view("output/paper/manuscript.html")`). Never render DOCX unless the user asks for it after the Viewer check.
- Never invent numbers, citations, or variable definitions. Cite only keys in `paper/references.bib`.
- Match causal language to the design (`ae-design` verdict table). Use `/ae-exogenous` to discover and stress-test documented assignment mechanisms before proposing a causal design; it is design discovery, not a causal verdict. Report failed diagnostics. `/ae-phacking` may deliberately screen outcomes, regressors, subgroups, and specifications by exploratory p-values to find research directions; preserve the full search record and label every selected result EXPLORATORY. Outside this discovery workflow, do not replace a planned specification with the lowest-p-value variant or present a selected p-value as confirmatory evidence.
- Results-first hypotheses: run the selected model and robustness scripts, compare all relevant evidence, then mark revised PLAN §9a hypotheses `origin=post-results` and manuscript claims exploratory; keep original predictions and contrary results. Do not imply preregistration or independent confirmation from the same sample.
- Always set `vcov` explicitly in `feols`; tables read SE type and cluster counts from the model.
- On Windows call `Rscript`/`quarto` directly; quote paths containing spaces. Use `ae-*` skills/agents/commands.
